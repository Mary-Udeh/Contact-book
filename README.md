# The user is to input their names, phone number and email

# For a user with misinformation, there's an option to edit the user's information

# You will need a browser, a laptop and internet connection

# Then download the repo from github

# Download the ZIP file to your locals

# UnZIP the folder

# Open the folder

# Open the index.html file to run the software
